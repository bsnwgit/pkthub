What is pktPCAP?
Every packet.
Every conversation.

pktPCAP is a self-hosted web application that transforms raw packet captures into actionable intelligence. Security and network teams can upload .pcap, .pcapng, or .cap files — or connect live capture sessions from remote hosts — and immediately begin analyzing traffic through an interactive, multi-tab dashboard.

Powered by an embedded AI engine (OpenAI or Anthropic), the platform lets analysts describe what they're looking for in plain language and receive protocol-aware insights without leaving the browser.

Designed for security operations centers, network engineering teams, and incident responders, pktPCAP runs as a hardened, SSL-secured service with role-based access control and enterprise SSO integration.

Data Flow
How pktPCAP Works

From raw bytes on the wire to AI-driven conclusions — here's the full picture.

Core Capabilities
Everything your team needs
to investigate network traffic.
📁
PCAP File Analysis
Upload one or multiple .pcap, .pcapng, or .cap files. Multiple captures are automatically merged and correlated into a unified session for holistic analysis.
📡
Live Feed Capture
Connect remote hosts via tshark (CLI) or Wireshark (GUI) for real-time feed streaming. The platform simultaneously records and presents live packet data as it flows — no file save required.
🤖
AI-Assisted Investigation
Ask plain-language questions about your capture — "Show me all failed authentication attempts" or "What is the largest data transfer?" — and receive protocol-aware, context-rich answers from OpenAI or Anthropic Claude.
🔬
Protocol Breakdown
Automatic multi-layer protocol decoding across HTTP, DNS, TLS, TCP, UDP, ICMP, and dozens more. Hierarchical views show distribution at a glance with drill-down into individual frames.
🔁
Stream Reconstruction
TCP and UDP streams are reconstructed and presented for full conversation-level review. Follow payloads across multiple packets to understand complete request/response cycles.
🌐
Endpoint Intelligence
Visualize all communicating endpoints, their traffic volumes, geographic and DNS context. Identify unusual communication patterns, top talkers, and unexpected external connections.
📊
Summary Dashboard
At-a-glance packet counts, byte totals, capture duration, top protocols, and anomaly highlights. An executive-ready snapshot is generated automatically from every upload or feed session.
💾
Export & Reporting
Export analysis results, AI findings, and protocol summaries for reporting and ticket documentation. Screenshot capture of the full dashboard is supported for visual record-keeping.
🔐
Hardened Access Control
Three role tiers (Admin, Analyst, Viewer) enforced server-side. TLS encryption end-to-end. Local username/password authentication plus enterprise SAML SSO integration for seamless corporate identity.
Role-Based Access
Built for every level
of your team.

Access is governed by three distinct roles — each scoped to the functions relevant to that user's responsibilities.

Administrator
Full Platform Control
Administrators have unrestricted access to all platform functions including the settings panel, user management, and service controls.
  • All analysis and capture features
  • User creation, editing, and deactivation
  • Role assignment and password reset
  • AI provider configuration
  • SSL certificate and SAML SSO settings
  • Log review and log-level control
  • Application restart / service management
Analyst
Investigation & Analysis
Analysts are the primary users — empowered with every capture, analysis, and export capability needed for day-to-day network investigation.
  • PCAP file upload and multi-file merge
  • Live feed connection and monitoring
  • Full AI-assisted chat and analysis
  • Protocol breakdown and stream reconstruction
  • Endpoint intelligence and conversation views
  • Export results and capture screenshots
  • Read-only access to settings (no changes)
Viewer
Read-Only Oversight
Viewers can review analysis results and dashboards without the ability to upload captures or modify any platform configuration.
  • View existing analysis sessions
  • Browse protocol and endpoint data
  • Read AI analysis results
  • View summary dashboards
🔑

Enterprise Authentication

pktPCAP supports both local username/password authentication and enterprise SAML 2.0 Single Sign-On. SSO users are automatically provisioned on first login, with role attributes synced from your identity provider on every session.

Architecture
Lightweight. Deployable.
Production-ready.

pktPCAP runs as a single systemd-managed service, requiring no container orchestration or external message queues.

Application Server

Python Flask serves the full single-page application over HTTPS. All API routes, authentication, and file handling run within the same process under a systemd service unit.

Packet Processing

Uploaded captures are parsed server-side using Scapy and dpkt, extracting all layers, conversations, DNS resolution, and flow statistics without leaving your environment.

AI Integration

The AI layer sends summarized packet context to your configured provider (OpenAI or Anthropic). Raw packet payloads are never forwarded — only structured metadata and analyst queries.

Data Storage

SQLite stores user accounts, role assignments, application settings, and session configuration. No external database engine required — zero-dependency persistence.

TLS / SSL

Auto-detected wildcard or host certificates provide end-to-end encryption. File presence at startup is authoritative — no configuration toggle required.

Key Design Principles
→
Self-contained — runs on a single server with no external service dependencies beyond AI APIs.
→
Packet data stays on-prem — raw captures are never transmitted to AI providers; only structured summaries are sent.
→
Encrypted in transit — all browser ↔ server communication is secured with TLS/HTTPS.
→
Role-enforced server-side — all access control checks happen on the backend, not in the browser UI alone.
