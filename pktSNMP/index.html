Platform Capabilities

Everything You Need to Monitor Your Network

From raw SNMP polls to actionable insight — all in one self-hosted platform with no SaaS dependencies.

📶

Real-Time Device Status

Live up/down status for every managed device, organized in a four-level hierarchy. Status dots roll up — one down device surfaces instantly at every level above it.

📡

Multi-Site Collection

Combine a built-in local pysnmp poll engine with remote OpenTelemetry Collector instances at distributed sites — no additional server infrastructure required per site.

⚠️

SNMP Trap Receiver

Listens on UDP 162 for unsolicited trap events from any SNMP-capable device. Traps are decoded, normalized, stored, and overlaid on metric charts as event markers.

📊

Metrics & Time-Series Charts

Per-interface traffic (bps and packets/s), error and discard rates, link speed, and operational status — charted with configurable time ranges and one-click CSV export.

🤖

AI-Powered Assistant

Ask natural-language questions about your network — "Which devices had errors in the last hour?" — and get instant answers sourced directly from your live telemetry data.

🚨

Intelligent Alert Engine

12 built-in rule types evaluate every 60 seconds — interface down, flapping, bandwidth saturation, error spikes, collector gaps, and more. Rules auto-resolve when conditions clear.

🗂️

OID Catalog

Browsable reference of all OIDs collected across your devices. Search by name or numeric OID, see current values, and understand what each metric represents.

🗺️

Flexible Storage Backends

SQLite for most deployments, or ClickHouse for very high-volume environments. Switch backends in the UI — no code changes or restarts required.

🔒

Enterprise Auth & RBAC

Admin, Analyst, and Viewer roles with JWT authentication. Supports SAML 2.0 SSO — roles assigned at the identity provider level with no per-user config in pktSNMP.

Collection Pipeline

From Device to Dashboard in Seconds

pktSNMP unifies local SNMP polling, remote OpenTelemetry collection, and UDP trap reception into a single normalized telemetry stream.

1

Discover & Configure

Register routers, switches, firewalls, and any SNMP-capable device. Assign to your Org → Group → Site → Device hierarchy. Set community strings or SNMPv3 credentials per device.

2

Collect & Receive

The built-in pysnmp engine polls registered devices on schedule. Remote otelcol-contrib instances push OTLP metrics over HTTP. UDP 162 captures unsolicited trap events.

3

Normalize & Store

All telemetry is normalized into a unified metric schema. Rows land in the time-series database with device, interface, OID, value, and timestamp indexed for fast query.

4

Evaluate Alerts

The alert engine runs every 60 seconds across all 12 rule types. Alerts fire when thresholds breach and auto-resolve when conditions clear — no manual acknowledgement required.

5

Visualize & Act

The React SPA delivers live status dashboards, per-interface charts, alert management, OID catalog browsing, and the AI assistant — all in the browser, no plugins required.

Platform Design

Built for Enterprise Network Environments

Self-hosted, single-server, zero cloud dependency — designed to run inside your network perimeter alongside the devices it monitors.

  • FastAPI Backend — Python 3.11 REST API serving auth, device management, SNMP ingest, alert evaluation, and AI query endpoints on port 8767.
  • React 18 SPA — TypeScript + Tailwind CSS frontend compiled to static assets and served directly by FastAPI — no separate web server or CDN required.
  • Dual Storage — pktsnmp.db manages control-plane config; snmp_timeseries.db stores all time-series metrics and trap events.
  • pysnmp Poll Engine — Local SNMP v1/v2c/v3 poller with configurable interval, community, and OID set per device.
  • otelcol-contrib Bridge — Remote OpenTelemetry Collector instances at distributed sites push OTLP HTTP metrics — no SNMP access across WAN required.
  • Alert Engine — Background evaluator on a 60-second loop, checking 12 rule types and writing alert events to the database.
  • JWT + SAML 2.0 Auth — Session tokens issued per login; optional SAML 2.0 SSO with role mapping at the IdP level.
