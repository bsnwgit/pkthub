pktFlow User Guide

This guide covers everything you need to use the pktFlow dashboard — from logging in to exploring flows, reading alerts, and exporting data for analysis.

📊 Platform Overview

pktFlow is a real-time network flow analytics platform. It collects NetFlow data from network routers and switches, stores it in a high-performance time-series database, and presents it through an interactive web dashboard.

As an end user, you interact with pktFlow entirely through your web browser. No software installation is required. You can access it from any device on the network.

ℹ️ pktFlow receives live traffic data from all monitored network segments. The data you see reflects actual traffic flowing through your organization's network infrastructure.

What You Can Do

  • View live traffic charts and top talkers across all monitored sites
  • Search and filter individual flow records by IP address, port, protocol, or time
  • Explore network topology — which devices are communicating with which
  • Monitor active alerts and review alert history
  • Export flow data to CSV or JSON for reporting
  • Manage your account password

🔐 Logging In

Open your browser and navigate to the pktFlow URL provided by your administrator. You will be presented with the login screen.

1

Enter Credentials

Type your username and password. These are provided by your pktFlow administrator.

2

Click Sign In

Press the Sign In button or hit Enter. If successful, you are taken directly to the Dashboard.

3

Troubleshoot

If login fails, confirm your username is spelled correctly. Passwords are case-sensitive. Contact your admin if you're locked out.

💡 Your session remains active for several hours. You won't be logged out mid-session unless you explicitly sign out or your admin resets your account.

📊 Dashboard

The Dashboard is the home page of pktFlow. It provides a real-time snapshot of network activity across all monitored sites.

Key Panels

  • Traffic Over Time — Line chart showing bytes and flows per minute. Use this to spot spikes or drops in traffic volume.
  • Top Talkers — The source IPs generating the most traffic. Useful for spotting unusual sources.
  • Top Destinations — The most contacted destination IPs or subnets.
  • Protocol Mix — Breakdown of traffic by protocol (TCP, UDP, ICMP, etc.).
  • Site Breakdown — If multiple collector sites are configured, this panel compares traffic volume per site.
  • Ingest Health — Shows whether pktFlow is actively receiving flows and how recently data was ingested.
ℹ️ All dashboard panels respect the currently selected time range. Change the range using the time picker in the top-right corner of the page.

🔍 Flow Explorer

The Flow Explorer gives you direct access to the raw flow records stored in pktFlow. You can search, filter, sort, and export any subset of the data.

Searching Flows

Use the filter bar at the top of the page to narrow results. You can filter by:

  • Source IP — exact IP or CIDR (e.g. 10.1.2.0/24)
  • Destination IP — exact IP or CIDR
  • Source Port / Destination Port — numeric port (e.g. 443)
  • Protocol — TCP, UDP, ICMP, or numeric
  • Site — filter to a specific collector site
  • Time Range — last 15m / 1h / 6h / 24h / 7d / custom

Reading the Flow Table

🖥️ Device View

Device View focuses on a single IP address, showing all traffic associated with that device — both inbound and outbound. Use this to investigate a specific host.

To open Device View for an IP, click any IP address link in the Flow Explorer or Topology pages. You can also navigate directly and type an IP address in the search box.

What You'll See

  • Total bytes sent and received over the selected time range
  • Top peers this device communicates with
  • Traffic over time chart for this device only
  • Full flow table filtered to this IP as source or destination

🗺️ Topology Map

The Topology page renders a live D3 force-directed graph showing network devices as nodes and traffic flows as edges. The thicker the edge, the higher the traffic volume between two devices.

Interacting with the Graph

  • Pan — Click and drag on the background to move the view.
  • Zoom — Scroll wheel to zoom in and out.
  • Drag nodes — Click and drag a device node to reposition it.
  • Hover — Hover over a node to see the device IP and traffic volume. Hover over an edge to see flow details.
ℹ️ The topology is built from actual flow records in the selected time window. Devices with no traffic in that period will not appear on the graph.

🚨 Alerts

The Alerts page shows all events triggered by pktFlow's rule engine. Each alert represents a condition your admin has configured as noteworthy.

Alert Types

TypeTriggers When
Data GapNo flows have been received from a site for longer than the configured threshold
New HostA previously unseen IP address appears in the flow data
Rate SpikeTraffic volume from a source exceeds the configured threshold
ThresholdA cumulative bytes or packets value crosses a defined limit
Port/ProtocolUnexpected port or protocol activity is detected

Alert States

  • Active — The condition is currently ongoing.
  • Resolved — The condition has cleared.
  • Acknowledged — A user has reviewed and acknowledged the alert.
⚠️ Only Admins can create, edit, or delete alert rules. Analysts and Viewers can read and acknowledge alert events.

🧰 Filtering & Search

Most pages in pktFlow share a common filter bar. Filters apply immediately and are reflected in all panels on that page.

Filter Tips

  • CIDR notation works for IP filters — enter 192.168.0.0/16 to match an entire subnet.
  • Multiple filters are combined with AND logic — all conditions must match.
  • Clear individual filters by clicking the ✕ icon next to each filter chip.
  • The time range selector affects all data on the current page.

📤 Exporting Data

You can export any filtered result set from the Flow Explorer for use in spreadsheets, SIEM tools, or reports.

1

Apply Your Filters

Use the filter bar to narrow the data to exactly what you need — time range, IPs, ports, etc.

2

Click Export

Find the Export button above the flow table. Choose CSV for spreadsheet use, or JSON for programmatic processing.

3

Save the File

Your browser will download the file. The export contains all fields for every record matching your current filters.

ℹ️ Exports are limited to the records returned by the current query. For very large time ranges, apply additional filters to keep the file size manageable.

🔒 Roles & Permissions

pktFlow uses three access roles. Your role is assigned by an administrator and controls what you can see and do.

RoleCan DoCannot Do
Admin Everything — including user management, settings, alert rules, and service restart —
Analyst View all data pages, search flows, export data, acknowledge alerts Manage users, change system settings, create alert rules
Viewer View dashboard, flow explorer, topology, and alerts Export data, acknowledge alerts, change any settings

👤 Password & Profile

You can change your own password at any time from the account menu in the top-right corner of the dashboard.

1

Open Account Menu

Click your username or avatar in the top-right of the navigation bar.

2

Select Change Password

Enter your current password, then your new password twice to confirm.

3

Save

Click Save. Your new password takes effect immediately. Your active session is not interrupted.

💡 If you forget your password, contact your pktFlow administrator. Admins can reset any user's password from the Users page.
