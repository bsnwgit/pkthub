Platform Capabilities

Everything You Need to Understand Your Network

From raw NetFlow packets to actionable insight — all in one self-hosted platform.

📊

Real-Time Traffic Dashboard

Live traffic charts, top talkers, protocol breakdowns, and per-site throughput — all updating continuously from live NetFlow data.

🔍

Flow Explorer

Search, filter, and drill into individual flow records by IP, port, protocol, time range, or site. Export results as CSV or JSON.

🗺️

Interactive Topology Map

D3-powered network graph that visualizes device relationships and traffic paths. See which devices are communicating and how.

🚨

Intelligent Alert Engine

Rule-based alerting for data gaps, new hosts, rate spikes, and port/protocol anomalies. Configurable thresholds with notification support.

🗄️

High-Performance Storage

ClickHouse columnar database stores billions of flow records with sub-second query performance. Time-series optimized for traffic analytics.

🔒

Role-Based Access Control

Admin, Analyst, and Viewer roles with JWT authentication. Manage users, reset passwords, and audit access from the built-in Users page.

📡

Multi-Site Collection

Receive NetFlow from multiple collector nodes across different network segments. Each flow is tagged with its source site for easy filtering.

⚡

Fast Ingest Pipeline

goflow2 decoder paired with Vector for field normalization, enrichment, and batched delivery. Handles sustained 150+ flows/sec per collector.

📤

Data Export

Export any query result to CSV or JSON for use in external tools, compliance reports, or custom analysis workflows.

Data Pipeline

From Packet to Insight in Milliseconds

A fully automated, five-stage pipeline takes raw network telemetry and delivers it to your browser in real time.

📶
1. Emit
Routers export NetFlow v9 via UDP
🧩
2. Decode
goflow2 decodes binary NetFlow to JSON
⚙️
3. Transform
Vector enriches fields and batches events
💾
4. Store
pktFlow normalizes and writes to ClickHouse
💻
5. Visualize
React dashboard renders live analytics
Technical Foundation

Built for Production.
Designed to Scale.

pktFlow is a fully self-hosted platform with no external dependencies or SaaS subscriptions. All data stays on your infrastructure.

  • FastAPI Backend — Async Python API server with JWT authentication, role enforcement, and a built-in alert rule engine.
  • ClickHouse Database — Columnar, time-series-optimized storage. Queries across billions of rows complete in under a second.
  • goflow2 + Vector Pipeline — Battle-tested open-source components for NetFlow decoding, field transformation, and reliable delivery.
  • React + D3 Frontend — Modern single-page dashboard with interactive charts, topology graphs, and live data updates.
  • Role-Based Security — Admin, Analyst, and Viewer roles with per-endpoint enforcement. Local auth with bcrypt password hashing.
