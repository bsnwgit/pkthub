Platform Capabilities

Everything You Need for Syslog Operations

From raw syslog packets to searchable, alertable, exportable insight — fully self-hosted.

📥

Dual-Protocol Ingest

Accepts syslog over UDP and TCP on a single port. RFC 3164 (BSD) and RFC 5424 (structured) formats are auto-detected and parsed on receipt.

⚡

ClickHouse Storage

Events land in a columnar MergeTree table optimized for time-series queries. Sub-second response across millions of rows with full-text search support.

🌐

Distributed Collectors

syslog-ng agents at remote sites forward with disk-buffer durability. The collector registry tracks each agent's status, site, and last-seen timestamp.

🔍

Syslog Explorer

Search all 17 event fields with filters for severity, facility, host, source IP, and custom time ranges. Export results to CSV or JSON at any time.

🔔

Alert Engine

Rule-based alerting for severity thresholds, rate spikes, keyword matches, host patterns, collector silence, and new collector auto-detection.

🛡️

Role-Based Access

Admin, Analyst, and Viewer tiers enforced at every API endpoint. JWT authentication with bcrypt password hashing and configurable session lifetime.

📊

Analytics Dashboard

Live metrics — events per second, severity distribution, top source hosts, facility breakdown, and collector health — all in a single view.

📓

Ingest Journal

File-based fallback captures all events if ClickHouse becomes unavailable. A background worker automatically replays and clears the journal on recovery.

🔐

HTTPS Everywhere

TLS-terminated FastAPI backend serves both the REST API and the React SPA on a single port. All auth tokens travel over encrypted transport only.

From Source to Storage in Milliseconds

A five-stage pipeline takes raw syslog datagrams and delivers structured, searchable events to your browser in real time.

📡
Collect
Remote syslog-ng agents receive and buffer events from local devices over UDP/TCP
2

3

Technical Foundation

Built for Production.
Designed to Scale.

pktLog is fully self-hosted with no external SaaS dependencies. All syslog data stays on your infrastructure, under your control.

  • FastAPI Backend — Async Python API with JWT authentication, per-endpoint RBAC enforcement, and a built-in alert rule engine.
  • ClickHouse Database — Columnar, time-series-optimized storage. 17-column MergeTree table with sub-second queries across millions of events.
  • syslog-ng Collectors — Remote agents with disk-buffer durability forward over TCP/UDP with TLS. Automatic reconnect on network interruption.
  • React + TypeScript Frontend — Modern SPA with Vite + Tailwind CSS, live dashboard, log explorer, alert management, and user administration.
  • SQLite Config Store — Lightweight storage for users, alert rules, collector registry, and platform settings — separate from event data.
